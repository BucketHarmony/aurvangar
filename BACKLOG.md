# Backlog

Do tasks in order. A task is done when its acceptance items are true and `./scripts/check.sh` is green.
Format: **ID** title · specs · deps. Acceptance tests are already in the test project with `Skip = "<task id>"`.
Two kinds:
- **Written tests** (M1 to M4-T3, and the water perf test): full bodies. Un-skip and make them pass.
- **Placeholder tests** (M4-T5 onward, `PendingAcceptanceTests.cs` and some perf tests): the name and the
  `Placeholder.Write("...")` text specify the test. Write the body first (move it into a per-system file), then
  un-skip. An un-skipped placeholder throws, so it cannot pass by accident. Add more tests where the spec calls for them.

Search for a task's tests with `grep -rn 'Skip = "M2-T3"' tests/`.

Milestone order is by risk: world and water before anything that depends on them.
